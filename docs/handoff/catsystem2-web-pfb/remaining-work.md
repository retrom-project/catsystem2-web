## VM 扩展段数值偏移

Main27 返回 VM 扩展段的数值偏移，**不是 C 进程指针**。Core 在旧 `0e9b` 和 W74 两个源码基线的同输入中确认：非 LIFO 删除后，旧数值偏移会指向后块 +16，旧 offset 的 free 返回 0。原完整 helper 静态同样按当前链表累计偏移并 erase 压缩，不保留洞；旧 T1 只覆盖 LIFO 有限使用。

Root 决定保持此 VM 规则，不做 Web 特有 allocator 修复、不改 schema。Config source-only checkpoint `c53b046e32e53f0cc0c9c71a6c3d3c24afb366fc` 的 `tests/native-cross-build-configuration-checkpoint.test.mjs` 和 [guest-memory 文档](../../../docs/native-guest-memory.md) 保存短诊断。当前诊断不是新 native 非 LIFO 动态证明；不写成已确认内存破坏或已修复 bug。续做须先核完整 callee/caller 与原生合法使用方式。

## 性能交接（冻结）
