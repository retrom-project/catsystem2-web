# 通用实现的完成标准

本项目的目标是独立的通用 CatSystem2 浏览器模拟器。NEKOPARA Vol. 3 是回归样本；
标题、主线或单个菜单通过，均不构成完成。retrom-runtime 接入在独立实现验收之后进行。

目标是运行时仅用 JavaScript 实现引擎，不加载或执行原 EXE、E-mote DLL 或 PPI DLL 的代码。
版本差异由 ABI 数据表达；原 EXE 和插件 DLL 的执行只用于离线取证和测试差分 oracle。
普通页面直接使用 Core，原 EXE/插件执行及其物理 checkpoint adapter 仅在显式 oracle
组合内。发行文件由实际 ordinary ESM 图和所需公开资源产生，不复制整个源目录或原后端。
地址与调用边界、禁止游戏特判、开发期契约和 x87 浮点差分要求见
[架构约束](architecture.md#目标与迁移状态)，均为完成条件。

`npm run check` 对实际普通入口图实行不可提高的零执行依赖上限：不允许原进程 owner、
EXE 调用、加载器或未审查的映像范围数值。现有格式 magic、IEEE/PCM/RGB 位操作、时间单位与指令预算操作数保留原字面量，
原始数值重叠计数仍输出，只有其具体 AST 数据用途被区分为普通常量。源码豁免标签、
更新基线和重定位计数接口均不进入该门禁。序列化物理状态的单个输入 owner 检查保留真实
计数；普通组合不能丢弃物理 payload，明确选择的 oracle 恢复组合才可承接它。

原迁移看板、生成器及固定 107 文件目标计划已经退出当前契约。各领域源码边界、真实
native 签名/准入数据、route 测试及实际 imports 产生的 Node 测试组继续维护；它们不把
未恢复槽或保留签名当成功实现。`build.json` 是本次实际构建的文件摘要，不是迁移状态表。

以 `references.json` 的固定输入为准：官方 SDK 4.01 中的引擎是 2.6.1.74，
目标游戏的引擎是 2.6.1.76。两版主 native 表分别有 1,009 和 1,055 个非空槽位，
不能用 SDK 发行版本代替某个作品的 ABI。MOT/generic、PTCL 1/2 与 PPI 2.0/2.1/2.2
也是不同接口，不能因为函数编号相同就共用分派。

实现按以下依赖顺序推进，所有必要项均属于当前目标：

1. 从固定二进制和官方文档建立逐项契约目录，包括未使用、废弃和保留槽位。
2. 修正 KCS 指令、地址空间、调用帧、native 控制返回和消息循环，支持暂停及恢复。
3. 实现对象、资源、变量、配置、任务和浏览器服务，使 main、sscript 及辅助 KCS
   完整运行。启动和菜单流程由游戏脚本决定；不以“运行到第一次 FES/CST 请求”截断。
4. 完成 FES/CST、MOT/KX2、自定义 SUBCOMMAND、图像、音视频、E-mote、PTCL 和 PPI。
   保留原始参数、状态、时序及对象生命周期。
5. 完成系统数据、已读标记、CG/音乐/动画鉴赏、回想、设置和保存/读取生命周期。
   游戏脚本中的对象句柄和任务必须能在新实例中重建。
6. 完成公共自制契约、SDK 用例、原生差分和真实游戏回归，并在隔离 PFB 中验收。

实现中不允许把未支持 native 返回 0、吞掉命令、按资源名称替换插件、补游戏专用全局变量、
硬编码游戏菜单入口、遍历脚本不渲染，计作相关功能已完成。
原生明确规定的空操作、无效引用和资源缺失行为需要自己的证据和测试。
需要浏览器语义替代的 OS 服务必须定义具体行为及测试；缺少服务不是成功的替代。

## 完整业务与性能的最终验收

Game 与 Route 的日常进度门槛和完整终点分账。完整批次显式传入
`CATSYSTEM2_FULL_ACCEPTANCE=1`，由实际测试进程的 `acceptance-mode` 注解确认；
不能凭父进程环境、1936/883帧进度停止或一次 SDK 教程通过追认完整游戏。
FULL 只移除原进度停止，保留原业务体、每个 until/action/expect 限制、
300 requested frames/180000ms 无进展保护及原完整模式的超时行为。

最终执行顺序是固定并校验实际服务的正常源码/ABI和输入来源，完成 Game UI，
再完成 Route；首个失败保留原证据，后续未执行项记 DNR。Route 须到14章、
两部原影片的实际解码/原跳过条件、>5000条唯一消息和返回标题，且无未支持调用或页面错误。
实际解码后跳过与自然播放结束分别验收。

完整模式的 teardown 另外保全 `terminal.cs2web` 与正常 IndexedDB userdata。
读取范围只限当前 Core 的 SaveStore、native-files、native-platform namespaces；
每个完整存储 record 独立用生产 codec 编码，保留其值、类型、buffer 共享及循环关系，
再以4MiB分块和浏览器/文件 SHA 核验传输。manifest 只含来源、帧、计数与摘要，
正文和存档内容仅在忽略的二进制 artifact 中。未完成或页面已关闭须明确记 unavailable，
不能称已捕获；完整业务已通过但保全失败时另报失败。CP 在正常 teardown 前捕获；
随后仅调用既有 Core.dispose/World.close，让其原 flush 和关闭回调完成，再以新的
readonly 连接导出实际已提交 userdata。close 失败单列并保首因，不能称完整结束。
完整模式的普通断言失败先保留页面供终态观察器取证，再由既有 fixture 关闭 context；
卡死帧仍遵循原 stall 关闭保护，页面已不可用时如实标记未捕获。观察器保留用例首错，
不额外推进帧、重放输入、改解锁或另造 flush/关闭规则。预点击 CP、终态 CP 和
各自 userdata 的实际源码/数据 namespace 分别记账，后续鉴赏与设置验收可复用真实终态。

| 完整 UI 义务 | 实际判据与未覆盖部分                                                                                                                                                                |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 保存/读取    | quick 与普通 slot、同源新实例恢复、继续实际脚本与画面/声音、旧 owner 释放；完整 checkpoint 的值、类型、共享关系和0 warm/no replay判据保留。                                         |
| 设置         | 区分已有语言/手柄路径与仍需覆盖的显示、文本/自动与跳过、各音量组/静音及输入设置；通过真实菜单更改，返回/重新启动后核实际持久状态与消费效果。                                        |
| 鉴赏/回想    | 真实 Game 的 CG、音乐、动画与回想按脚本登记/解锁，实际查看或播放、导航/返回、重启后核系统数据；声音/影片确实推进并正确停止或结束。SDK gallery是独立来源，不能替代 Game 的这些项目。 |
| 输入/模式    | 键盘、鼠标、触摸、手柄与真实 DOM fullscreen/暂停恢复按各自原用例验收，保留实际事件、owner、焦点和模式恢复，不伪造菜单或流程变量。                                                   |

性能另用未替换的浏览器 RAF 路径，不运行 `frameClock/nativeGameFrame` 驱动。
logo、title、dialogue、真实可见 M2 以及密集效果五场景各须有同步只读的到达判据和
真实 owner/状态事实；不能按预定帧编号贴标签。采样期间离开场景、隐藏页面、
替换 RAF 或更换 Core/World/renderer均使该窗口失效。

每个窗口分别报告浏览器 RAF 间隔与回调速率、World 实际帧推进/step/tick、
render 完成及可用的 renderer.present 完成节奏。方法耗时 mean/max、
最近有界总体的 p95和超出60Hz帧预算的次数均标明总体；只收到 RAF 回调不构成60fps。
Canvas present完成并不是物理显示扫描时间。最终60fps结论须绑定当前开发机、
实际浏览器/GPU或软件 renderer、viewport、可见性、采样时长与真实运行/渲染证据。

内存只报告可取得的真实 JS heap、对象/任务/资源计数、RGBA view 长度和去重后的
相关 backing buffer长度。共享 view 不重复计作独立分配，buffer未使用部分明确保留；
这些量不是 GPU、音频、worker或进程总内存。不可用项记 null，不能补0或推算达标。
