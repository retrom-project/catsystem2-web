# 通用实现的完成标准

本项目的目标是独立的通用 CatSystem2 浏览器模拟器。NEKOPARA Vol. 3 是回归样本；
标题、主线或单个菜单通过，均不构成完成。retrom-runtime 接入在独立实现验收之后进行。

以 `references.json` 的固定输入为准：官方 SDK 4.01 中的引擎是 2.6.1.74，
目标游戏的引擎是 2.6.1.76。两版主 native 表分别有 1,009 和 1,055 个非空槽位，
不能用 SDK 发行版本代替某个作品的 ABI。MOT/generic、PTCL 1/2 与 PPI 2.0/2.1/2.2
也是不同接口，不能因为函数编号相同就共用分派。

实现按以下依赖顺序推进，所有必要项均属于当前目标：

1. 从固定二进制和官方文档建立逐项契约目录，包括未使用、废弃和保留槽位。
2. 修正 KCS 指令、地址空间、调用帧、native 控制返回和消息循环，支持暂停及恢复。
3. 实现对象、资源、变量、配置、任务和浏览器服务，使 main、sscript 及辅助 KCS
   完整运行。启动和菜单流程由游戏脚本决定；不以“运行到第一次 FES/CST 请求”截断。
4. 完成 FES/CST、MOT/KX2、自定义 SUBCOMMAND、图像、音视频、E-mote、PTCL 和 PPI。
   保留原始参数、状态、时序及对象生命周期。
5. 完成系统数据、已读标记、CG/音乐/动画鉴赏、回想、设置和保存/读取生命周期。
   游戏脚本中的对象句柄和任务必须能在新实例中重建。
6. 完成公共自制契约、SDK 用例、原生差分和真实游戏回归，并在隔离 PFB 中验收。

实现中不允许把未支持 native 返回 0、吞掉命令、按资源名称替换插件、补游戏专用全局变量、
硬编码游戏菜单入口、遍历脚本不渲染，计作相关功能已完成。
原生明确规定的空操作、无效引用和资源缺失行为需要自己的证据和测试。
需要浏览器语义替代的 OS 服务必须定义具体行为及测试；缺少服务不是成功的替代。

各领域的验收边界如下。

| 领域          | 必须完成的行为                                                                                    | 验证                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| KCS VM        | 全部有效 opcode、类型标志、平坦内存/共享内存/扩展块、调用与多字返回、所有 native 控制码、调试位置 | 原始 x86 处理器差分；公共调用/指针/等待/恢复用例                             |
| native 与任务 | 两个固定主 ABI、generic/MOT、对象消息、任务创建/销毁/同步和队列消息、绑定的变量域                 | 全槽目录；逐族契约；完整 main/sscript，未知调用为 0                          |
| 内容与格式    | 带归档限定的 VFS、patch 优先级、目录输入、格式边界与原始资源标识                                  | 同名资源冲突用例；SDK/游戏全语料解析与解码                                   |
| FES/CST       | 官方普通命令、对象命令、对象变体、语法、系统变量、选择、消息样式、分支与异步脚本                  | [逐项目录](fes-cst-compatibility.md)；公共脚本；SDK 源码与编译样本；原生时序 |
| MOT/KX2       | 正确绑定、运动参数、SUBCOMMAND、逐帧更新及中途恢复                                                | SDK 全语料；原生数值与逐帧状态差分                                           |
| 渲染与 E-mote | 几何、排序、混合、遮罩、色调、模糊、转场、文本布局、模型/动作/物理                                | 自制像素用例；真实资源；固定输入的逐帧原生对照                               |
| PTCL/PPI      | 两版脚本全部 native；原生 DLL 的真实 ABI、生命周期、内存、宿主函数和渲染状态                      | [粒子覆盖目录](ppi-coverage.json)；SDK 全脚本；DLL 差分与输出比较            |
| 音视频        | 通道、循环/完成事件、音量、tag/lv、暂停恢复、影片结束及跳过                                       | 真实解码和时间推进；状态恢复；原生时序                                       |
| 系统与模式    | 完整原生初始化、配置、CG/动画/音乐登记与鉴赏、回想、已读与流程变量                                | 原始系统脚本；模式全分支；重启后持久状态                                     |
| 保存与输入    | 任务/VM/界面/媒体/转场恢复；键盘、触摸、鼠标、手柄；退出释放                                      | 新实例重放输入；同状态继续执行与画面；资源释放                               |
| 发行          | 可复现 standalone 构建、公共 CI、来源/许可、无私有资产                                            | 构建摘要；公共浏览器测试；分发内容检查                                       |

各目录的 `implemented` 只代表其明确列出的契约及证据。仍有 `partial`、`missing`、
未恢复语义、没有接入执行路径的模块或未通过的必要验收时，整体状态保持开发中。
原始研究记录、SDK/游戏资源、ELF oracle、截图、IDA 数据库和验收日志仅存于忽略的本地目录。
