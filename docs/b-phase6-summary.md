## 数值和实现选择

- 两版 Cube 的 grid-height 行为差异通过既有 `capabilities` 中新增的 `cubeFlipGridHeightProduct` 布尔字段表达，沿用既有 capability 结构登记已验证语义；ABI 数据格式与运行时版本选择规则不变。
- 原 Break/Glass 的未初始化 pivot.w 保留 oracle 证据，JS 规范为 0。有限输入差分保持既定精度门槛。
- 原 paired-bitmap 非零 origin 与 RGB24 固定 DWORD 步长会跨分配读取，JS 显式抛出 RangeError。该限制需要在最终验收中列明。
- C8 不透明 caller identity 按 VM cell 或 task pointer 归一化，保留可观察的身份比较和序列状态。
- JPEG 使用原 IJG IFAST 整数 IDCT 与颜色转换。自行生成的 baseline/progressive、4:4:4/4:2:0 样本两 ABI 逐字节一致，原 snow atlas 和粒子帧也逐字节一致。来源和许可证已登记。
- 插件修改 FPCW 后的跨调用影响按已批准边界处理，保留旧六种 FP 状态证据，浏览器采用正常脚本环境 PC24 结果。
